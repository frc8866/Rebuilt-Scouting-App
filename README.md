
How to run scouting at comps:
1. Put tablets on charge immediately after arriving at comp.
2. Create the schedule as soon as TBA releases the comp schedule. For details on how to do this, look at the README in ScoutingScheduler.
3. Once the schedule is in the backend, connect all tablets to a hotspot and make sure they have received the schedule. Afterwards, disconnect them.
4. All tablets should have a battery pack connected at all times, and extra battery packs should be on charge at all times.
5. Make sure all six tablets have unique positions (Red 1, Red 2, Red 3, Blue 1, Blue 2, Blue 3). To change this, look in the top right corner of the main menu and click the position label. The password is the current year, i.e, "2026" for Rebuilt.
6. Make sure scouters have their tablets when the opening ceremony starts. Oversee scouting and fix any technical problems.
7. When you get a break, such as lunch, end of day, etc, reconnect tablets to wifi so they can upload data. This can also be done at the hotel.
8. Please return from lunch about 5-10 minutes early to make sure scouters can keep scouting after lunch. Sometimes people miss the first match after lunch. Try and make sure this doesn't happen.
9. If an anomaly happens such as a match ending as a tie or a match being replayed, please write down the match number.
10. Write down names of people who miss scouting. Seriously
11. Cut off scouting about 5 matches before alliance selection, connect all tablets to make sure data gets uploaded (IMPORTANT).

    If you have problems please find me at comp or text me! Scouting will not always go perfectly and that is ok. - Abigail
